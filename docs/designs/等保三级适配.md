## 2. DocManage 当前等保准备度：60%

### ✅ 已满足项

| 等保控制项 | DocManage 实现 |
|-----------|---------------|
| **访问控制** | RBAC v3 + 179 权限码 + 6 data_scope 模式 |
| **数据完整性** | SM3 + SHA-256 + WORM + DB 触发器禁改 |
| **安全审计** | audit_log SM3 哈希链 + 触发器禁 UPDATE/DELETE |
| **应用安全** | SQL 注入防护 + 输入过滤 |
| **身份认证** | JWT + 密码 bcrypt 哈希 |
| **不可变存储** | pdf_lock 触发器防篡改 |

### ❌ 缺失项

| 缺失项 | 等保要求 | 优先级 | 工作量 |
|--------|---------|--------|--------|
| **多因素认证（MFA）** | 身份认证强化 | P0 | 3-5 天 |
| **异地备份（S3/OSS）** | 数据备份恢复 | P0 | 2-3 天 |
| **国密 SM2 HTTPS** | 密码应用安全 | P0 | 3-5 天 |
| **国密 SM4 数据加密** | 数据保密性 | P1 | 3-5 天 |
| **堡垒机 + 操作审计** | 运维安全 | P1 | 5-10 天 |
| **漏洞扫描 + 渗透测试** | 入侵防范 | P1 | 3-5 天 |
| **日志集中管理（SIEM）** | 安全运营 | P1 | 5-10 天 |
| **应急预案 + 演练** | 应急响应 | P2 | 2-3 天 |
| **等保测评 + 备案** | 认证 | P0 | 1-2 月 |

## 3. 实施路径

### 阶段 1：基础补齐（1-2 月）

- 多因素认证（MFA）
- 异地备份（S3/OSS）
- 国密 SM2 HTTPS
- 漏洞扫描

### 阶段 2：深度合规（2-3 月）

- 国密 SM4 数据加密
- 堡垒机 + 操作审计
- SIEM 日志集中
- 应急预案 + 演练

### 阶段 3：等保测评（按需 1-2 月）

- 选择测评机构
- 正式测评
- 公安机关备案
- 获得等保三级备案证明
