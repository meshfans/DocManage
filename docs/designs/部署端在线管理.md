# 详细设计：部署端在线管理

> **任务编号**：todo.md 展开项  
> **优先级**：P1  
> **工时估算**：3-4 天

## 1. 目标

在管理端看到「所有已部署的 DocManage 客户实例」及其状态，解决：
- 有哪些客户在用？
- 最后登录是什么时候？
- License 是否快过期？

## 2. 数据库设计

### 2.1 deployment 表

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | INTEGER PK | 自增 |
| `snowid` | TEXT UNIQUE | 实例全局雪花 ID |
| `customer_name` | TEXT | 客户名 |
| `machine_code` | TEXT UNIQUE | 实例硬件码 |
| `license_key` | TEXT | License 签名串 |
| `license_expires_at` | INTEGER | 到期时间（Unix 秒） |
| `version` | TEXT | Go 注入的版本号 |
| `status` | TEXT | `active` / `inactive` / `expired` / `offline` |
| `last_heartbeat_at` | INTEGER | 最近心跳 |
| `last_login_at` | INTEGER | 最近登录 |
| `created_at` | INTEGER | |
| `updated_at` | INTEGER | |

### 2.2 deployment_event 表

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | INTEGER PK | |
| `deployment_id` | INTEGER | FK |
| `event_type` | TEXT | `register` / `heartbeat` / `login` / `license_change` |
| `detail` | TEXT | JSON 细节 |
| `created_at` | INTEGER | |

## 3. API 清单

### 客户端上报（部署实例自己）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/deployment/report` | 心跳上报 |
| POST | `/api/deployment/report-login` | 登录事件上报 |

### 管理端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/deployments` | 实例列表 |
| GET | `/api/admin/deployments/:id` | 实例详情 |
| PUT | `/api/admin/deployments/:id/status` | 更新状态 |
| POST | `/api/admin/deployments/:id/issue-license` | 签发 License |
| GET | `/api/admin/deployments/dashboard/stats` | 概览统计 |

## 4. 前端页面

**路由**：`/system/deployments`

**页面**：
1. **实例列表**：表格 + 顶部统计卡
2. **实例详情**：基本信息 + 事件时间线
3. **License 签发弹窗**：表单 + 下载

## 5. 调度器整合

| 任务 | 频率 | 说明 |
|------|------|------|
| `deployment_heartbeat_check` | 每小时 | 24h 无心跳置 offline |
| `deployment_license_expiry_check` | 每天 08:00 | 到期前 30/15/7/3/1 天提醒 |

## 6. 开发步骤

| 步骤 | 内容 | 产出 |
|------|------|------|
| S1 | 新增表 + Go model | `database/deployment.go` |
| S2 | 上报 API + 自注册 | `handlers/deployment.go` |
| S3 | 管理端 API + 登录回填 | `handlers/admin_deployment.go` |
| S4 | 前端页面 | `views/system/deployment/*` |
| S5 | 调度任务 | `services/deployment_jobs.go` |
